Threat & Leakage Vectors Mitigated

docs/threat-model.md documents 7 concrete leak vectors: host-agent Read/Bash tools, shared LLM context memory, OS clipboard, IDE logs/shell history, CA's spawned rebuild agent, REA bundles on disk, and mixed deep_private metadata.

Recommendation: pair Topology (b) with container/OS user separation whenever strict IP isolation matters.

Frequently Asked Questions

Does carea create a legal clean-room guarantee?

No. carea is an engineering process aid. craft-anything-cli --clean-room is a tool-level guard, and a single developer operating both Analyst and Builder cannot achieve legal clean-room separation.

Why does carea parity-report return partial when rebuild_check passes?

By rule, passed requires both Axis 1 (CA observable check) and Axis 2 (REA behavioral verification) to finish completely with zero partial coverage or unresolved limitations.

Why did REA fail startup with full schema profile errors?

Starting in rea-agents 6.10.0, REA rejects full input/output schema profiles. Switch to compact input and off output via carea mcp-profile rea-hot-cold.
