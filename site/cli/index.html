CLI Reference & Schema v1.1.0

Install cleanly via pip install --no-deps . or run directly through scripts/carea and scripts/carea.ps1.

carea init <dir>

Creates 4 separated lanes (analyst-evidence/, airlock/, builder-workspace/, verification/) and .carea/config.json. Mode 4 adds loud NOT CLEAN-ROOM banners.

carea doctor

Checks rea, Node.js, and craft-anything-cli against compat/matrix.json; warns on REA full schemas (>=6.10.0) and CA --all-tools.

carea validate-handoff <file>

Validates 1.0.0 and 1.1.0 handoffs without third-party dependencies and blocks deep_private: true alongside clean-room flags.

carea airlock-lint <dir>

Heuristic leak scanner catching fenced code, inline bitwise/branch snippets, asm, hex dumps, 4+ hex constants, minified JS, base64, assets, secrets, obfuscated emails, and long prose.

carea airlock-sign <handoff>

Refuses unless airlock-lint is strictly PASS, deep_private is false, and both --reviewer and --confirm-human-review are passed.

carea isolation-check [dir]

Checks symlink/junction overlap between builder-workspace and analyst-evidence and prints recommended host-agent deny snippets.

carea spec-draft <bundle>

Extracts opaque ev_..., unk_..., and obl_... IDs cleanly from REA bundles without copying raw code or payloads; always stamped DRAFT.

carea parity-report

Merges CA observable results and REA verification outputs; marks obligations passed only when both axes complete with zero partial limitations.

carea return-feedback

Outputs failing test vectors and observable UI/pixel differences for Lane B, running self-lint to prevent accidental code leakage.

carea mcp-profile <preset>

Prints lean JSON configs for REA and CA; --apply renders a unified diff and asks interactive confirmation before writing.
