Orchestration Matrix

Six Modes & Two Lane B Topologies

Every workflow states its entry point, exact verified upstream tools, authorization gates, and honest parity boundaries.

Mode 1 · /ca · clean-room-ui

Clean-Room UI / Web Rebuild

Use when visible screens, CSS responsiveness, and public interactions are sufficient. Runs craft-anything-cli --clean-room without --all-tools.

Tools: core_session_show, web_site_open, web_site_capture, rebuild_start, rebuild_check, web_pixels_compare.

Limit: Observable UI checks only; internal algorithms stay out of scope.

Mode 2 · /carea · two-team-process

Two-Team Clean Room Process

REA Lane A exports evidence to analyst-evidence/; spec-draft + airlock-lint + human airlock-sign gate airlock/; fresh CA --clean-room Lane B builds.

Verdict Rule: carea parity-report marks passed only when both CA and REA axes finish completely.

Mode 3 · /rea · deep-verification

Deep Investigation & AgentEnv

REA-first binary, ELF/PE/Mach-O, JS/Electron, managed .NET, or UEFI inspection with formal verify_reconstruction and AgentEnv export.

Tools: open_binary, analyze_function, inspect_uefi_firmware, export_environment_bundle.

Mode 4 · /carea · private-deep-rebuild

Private Deep Rebuild (NOT CLEAN-ROOM)

WARNING: Combines REA Deep + CA --deep for owned/authorized codebases only. Sets deep_private: true and prints mandatory NOT CLEAN-ROOM banners.

Schema validation strictly forbids combining deep_private: true with clean-room modes or airlock.status = "passed".

Mode 5 · /carea · game-rebuild

Game Rebuild Path (Unity / Unreal / Godot)

Rebuilds gameplay loops using --build-with and original generated assets (assets_image_generate, assets_model_generate).

Strict Gate: Zero anti-cheat bypass and zero copied sprites/meshes. Note CA game_* extraction tools are blocked in --clean-room (Deep-only).

Mode 6 · /carea · android-mobile

Android / Mobile App Path

Pairs REA APK/DEX/JNI/Flutter inspection (inspect_android_package, inspect_dart_aot) with CA observable adb UI capture (adb_screenshot_take, adb_window_show).

Limit: Requires authorized APK/test device and Android Platform Tools (adb).

Lane B Topologies: Who Is the Builder?

Topology How Lane B Runs Isolation Strength Key Weakness / Mitigation
topology: "a" Orchestrator calls craft-anything-cli rebuild --clean-room; CA spawns child builder agent. Moderate Initial prompt and parent session origin overlap; share same OS user unless containerized.
topology: "b" Lane A closes completely; fresh Session 2 loads craft-anything-cli mcp --clean-room only (no REA MCP). Stronger (Recommended) Zero shared LLM context window. Enforce workspace permissions via carea isolation-check and see docs/threat-model.md.
