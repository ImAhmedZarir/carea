Two-Team Boundary

Executable Airlock Gates Replace Honor System

Instead of relying on prompts alone, carea checks directory boundaries (isolation-check), drafts ID-only spec skeletons (spec-draft), scans heuristically for inline code, asm, hex offsets, base64, assets, secrets, and obfuscated emails (airlock-lint), and blocks airlock.status = "passed" until explicit human confirmation (airlock-sign).

Context Hygiene

Avoid 580+ Tool Overload

Never load both complete catalogs simultaneously. Pair REA hot-cold or scoped REA_MCP_TOOL_FAMILIES with CA --clean-room (omitting --all-tools).

Dual-Axis Parity

Visual Likeness + Behavioral Proof

Craft Anything verifies responsive UI pixels and flows (rebuild_check, web_pixels_compare), while REA verifies obligation ledgers and capture contracts (verify_reconstruction). carea parity-report marks an obligation passed only when both axes finish completely.

Strict Invariant

Private Deep Mode Cannot Pose as Clean-Room

Mode 4 (deep_private: true) prepends mandatory NOT CLEAN-ROOM banners across specs and parity reports, and schema validation (v1.1.0) rejects pairing deep_private: true with clean-room modes or passed airlock status.

5-Minute Quickstarts

Pick the entry point matching your task — each skill has non-overlapping triggers and keeps context lean.

Combined Two-Team Pipeline (/carea)

Use when hidden state machines or API contracts require REA analysis before a fresh CA --clean-room rebuild.

pip install --no-deps .
carea doctor
carea init ./pulse-rebuild --mode two-team-process --topology b --target-name pulse-timer
carea isolation-check ./pulse-rebuild
carea spec-draft ./pulse-rebuild/analyst-evidence/bundle.json --out ./pulse-rebuild/airlock/clean-room-spec.md
carea airlock-lint ./pulse-rebuild/airlock --strict
carea validate-handoff ./pulse-rebuild/airlock/carea-handoff.json

REA-First Investigation & Verification (/rea)

Use for binary, JS/Electron, .NET, APK/Flutter, UEFI/firmware analysis, verify_reconstruction, or AgentEnv export without UI rebuilds.

npm install -g rea-agents@6.10.1
carea mcp-profile rea-hot-cold
# In session: inspect with open_binary / analyze_javascript_application -> export_evidence_bundle

Craft Anything-First Observable Rebuild (/ca)

Use when visible layouts, screenshots, and public interactions provide everything needed for a --clean-room rebuild.

python examples/sample-target/server.py --port 4173
carea mcp-profile ca-clean-room
craft-anything-cli rebuild http://127.0.0.1:4173/ "Build accessible countdown timer" --clean-room
